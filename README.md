# Барака CRM

Реестр инвесторов и пулов, связанных с договорами мурабаха (исламская рассрочка).

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой

Проект задеплоен через Vercel. Подключён к Supabase (база данных + авторизация).

## Структура

- `src/supabaseClient.js` — подключение к базе
- `src/AuthContext.jsx` — авторизация и профиль пользователя
- `src/Login.jsx` — страница входа
- `src/Dashboard.jsx` — основной layout с навигацией
- `src/InvestorsView.jsx` — модуль инвесторов (капитал, доли, пулы)
- `src/ContractsView.jsx` — модуль договоров мурабаха (клиенты, пул финансирования)
